
# Lara Valentim | Portfólio

## Sobre o projeto

Este é meu portfólio pessoal, desenvolvido para apresentar minha trajetória na tecnologia, minhas habilidades, conhecimentos e projetos de desenvolvimento.

O projeto faz parte da minha jornada de aprendizado no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Projetos apresentados

- [Ordem para Pagamento com Melhorias](https://github.com/laravinhandelly/ordem-para-pagamento_c_melhorias)
- [App Inspetor e Empresa](https://github.com/laravinhandelly/App_Inspetor_Empresa)
- [DEVLMS - APP UOM](https://github.com/laravinhandelly/DEVLMS-APP-UOM)

## Funcionalidades

- Menu de navegação entre as seções.
- Alternância entre tema claro e escuro.
- Menu responsivo para dispositivos móveis.
- Formulário de contato com mensagem de confirmação.
- Layout adaptável para diferentes tamanhos de tela.
